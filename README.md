Netter is a Y Combinator-backed AI data platform ("Build with your data, not your engineers") that centralizes a company's scattered data sources, cleans and enriches them into a living ontology, and lets teams turn that into dashboards, workflows, pipelines and AI-generated apps through chat rather than tickets. Netter exposes a public REST API (the "DMI Backend", rooted at /api/v1 on api.netter.ai) for programmatic file upload plus a broad application surface covering projects, pipelines, ontology entities/rows/relationships, integrations (Databricks, Snowflake, Salesforce, Slack, GitHub, Notion, PostgreSQL and more), dashboards, permissions and an assistant. Auth is an ntr_-prefixed bearer API key; enterprise controls include SAML 2.0 SSO and SCIM 2.0 provisioning.

**Areas:** Company · Data · Data Platform · Analytics · Artificial Intelligence · Ontology · Data Integration · Pipelines · ETL · Y Combinator

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Netter: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
